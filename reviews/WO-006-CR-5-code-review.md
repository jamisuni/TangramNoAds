## Per-item answers to the CR-5 row

2. **041.** Nothing can reach release (see the verdict line). V-08 covers it in both directions: it denies both classes in release and requires them with `--expect-debug`. `@Volatile` state is sound: tests set it before launch, `TestConfigRule` nulls it before and after, and every test closes its scenario with `use`. The recreate case (`decisionF6`) reads it again at attach as intended.
3. **042.** Coverage: it resets and checks size, density, `font_scale`, both rotation keys, the navigation overlay (API 29+), airplane, and mobile data and Wi-Fi on API 26. This equals the globals the kit writes (grep of every `settings`/`wm`/`cmd`/`svc` call). Baselines are per AVD: API 37 accelerometer 1 and nav 2, null accepted only for `font_scale` and `user_rotation`. The nav poll (15 s, read-first) is right, and the fixed 2 leaks to exit 1 as the live round showed. Exit codes 0/1/2 are right, argparse errors exit 2, and an unknown AVD is exit 2. A device lost mid-reset ends in exit 2 because the verify reads are hard. Gaps: N8 to N11.
4. **043.** `gap(c)` is read in `trayScaleFor`, `compute` (row separation and `trayGap`) and nowhere else. On tablets the single row means no inter-row effect, and the width-bound scale grows only on narrow tablets. `trayBadgeRect` moves 2 dp. No REQ names the gap. `PlaceSecondarySweepTest` (the DA-75 placement, 13 puzzles by 9 sizes) and `TraySizeSweepTest` both ran after the edit with 0 failures (XML at 09:47:12, source edit at 09:47:04). Not affected beyond that. The sweep is real: it goes through `PlayLayout.compute`, asserts every cell at least 48 dp in both axes in every window from 560 dp tall, row counts, and inside-the-area; the non-asserting interim print is labelled.
5. **044.** The dex reader is correct against the format and fail-closed (fuzzed, see Method; N6 for the two weak spots). `DENIED_SDK` is defined-class prefixes only, no over-reach (references never count; AndroidX defines none of them); under-reach is N5. The `aapt2` parse matches the real `E:`/`A:` shape; its scope is too narrow (S2) and it has no positive control (N7). The stale guard's input set mirrors the build globs, ignores `build/`, `.gradle/` and `.git`, and is tested for both inclusion and exclusion; it fails in the safe direction (a touched but unchanged file gives a spurious exit 2, never a pass). The own build deletes the old output first (V-04's `_build`). `--expect-debug` works on the real debug APK.

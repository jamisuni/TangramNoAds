# WO-004 — #Browsing + `store`: many puzzles, saved progress

**Status:** **Closed 2026-10-03**  ·  **Mode:** Full
**Kicked off by:** Jami / 2026-10-02 ("continue with all reqs"; `build-map.md` §2, governance row 8), opened by the AI right after the WO-003 close (2026-10-03)  ·  **Plan approved:** 2026-10-03 by the AI under row 7, after plan review spot-check "forward" (`tasks.md` v1.2)

## Goal

Let the player move between all the puzzles and keep their progress. Browse with ‹ › and the
overview grid, and see each puzzle's state. Saved pieces survive closing the app, and a fresh
install opens on the rating-1 mini puzzle. This also retires the WO-003 debug-only `puzzle` extra
or keeps it debug-only (DA-23).

## Scope  *(the traceability anchor — build-map.md §2, WO-004 row)*

- **Implements features:** #Browsing and its leaves (code home `browse`), plus the `store`
  module behind `IProgressStore`. The acceptance IDs are **REQ-003 A1–A2, REQ-024 A1–A3,
  REQ-025 A1–A3, REQ-026 A1–A2 and REQ-050 A1–A3**.
- **Carried IN (must be closed here):**
  - from WO-002: the fresh-install **on-screen** parts of REQ-040 A1, REQ-041 A1 and REQ-045 A1.
    A fresh install opens on a rating-1 mini puzzle with the warm-ups next. WO-002 asserted
    these at library level only.
  - from WO-003:
    - saving the `PlaySession` state (DA-26: no persistence until WO-004);
    - the debug `puzzle` extra (DA-23: retire it, or keep it debug-only);
    - code review N4: an empty library at `puzzles.first()` must not crash (G-10);
    - the `AppViewModel` session wiring.
  - from P2: **G-09**, a frozen v1 save fixture. The first save format is v1. Any later
    change to it is a data migration, and that is a **hard-stop** (AGENTS.md).
- **Carried OUT:** → WO-008 (puzzle and play times through `IProgressStore`, REQ-005/029–031);
  → WO-007 (settings: reset progress via `IProgressStore`, REQ-034).
- **Governed interfaces touched:** `IProgressStore` (**notify** tier; the first
  implementation, so any signature change is a logged `contract-delta`) · `IPuzzleLibrary`
  (locked; consumes only).
- **Out of scope:** settings, time, sounds, DevTools, tablet layout acceptance (WO-006).

## Mode justification

first implementation, and two new modules (`browse`, `store`).

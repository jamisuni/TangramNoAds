**Status:** Done (closed 2026-10-02)  ·  **Mode:** Full

## Goal

Build the lock engine the whole game rests on: exact piece geometry in the
kernel (TYPE-001, TYPE-003), the TYPE-004 lock search, and the `play`
module's drop resolution — a dropped piece locks at the best anchored spot or
goes home, the landing preview shows exactly where a release would lock, and
in a mini puzzle a missed drop makes the outline corners pulse once.

  — **REQ-019 A1..A4, REQ-020 A1, REQ-021 A1..A2, REQ-051 A1..A2** at engine /
  state level (9 acceptance IDs; build-map.md §2). Code home `play`, engine in
  `kernel` (O-01). **Carried to WO-003:** REQ-020 A2 ("no error message") and

  mirror transforms, exact arithmetic (ADR-003, outside `kernel.model`),

  WO-003), F23 notes on REQ-019 acceptance wording (A1 "locks there exactly" =
  at the TYPE-004 winner; A3 = no anchor within the lock distance; A4 = the

# WO-002 — #Content: the puzzle library behind IPuzzleLibrary

**Status:** Done (closed 2026-10-02)  ·  **Mode:** Full
**Kicked off by:** Jami / 2026-10-02 ("continue with all reqs"; WO sequence `build-map.md` §2, governance row 8)  ·  **Plan approved:** 2026-10-02 by the AI under row 7, after plan review spot-check "forward" (`tasks.md` v0.7)

## Goal

Ship the real puzzles to the app: a `content` module that packages the
puzzle files of `Tangrams/` at build time, reads format `tangram-puzzle/1`
into the locked `IPuzzleLibrary` contract types (exact solution geometry,
both titles, kind, rating, picture, review flag), and lists them in the
required order — so WO-003 can put a real puzzle on the board.

## Scope  *(the traceability anchor)*

- **Implements features (build-map.md §2, WO-002 row):** #PuzzleShapes,
  #PuzzleArt, #PuzzleOrder, #PuzzleWarmups, #PuzzleMini under #Content —
  **REQ-007 A1–A2, REQ-038 A1–A2, REQ-039 A1 (library level), REQ-040 A1–A2,
  REQ-041 A1–A2, REQ-045 A1–A2 (library / engine level)**. Code home `content`.
- **Carried out:** → WO-003: REQ-039 A1 and REQ-045 A2 on screen, the
  on-device library check (`rejected` empty, count = index lines) and the
  release-APK `tangrams/` = `Tangrams/` check, path-data `d` validation;
  → WO-004: the fresh-install-on-screen parts of REQ-040 A1, REQ-041 A1 and
  REQ-045 A1 (asserted here on the library list); → WO-009:
  REQ-039 A2, REQ-042 A1–A3 (release checklist, decisions F17).
- **Also in this WO:** the golden exporter gains validator verdicts for every
  puzzle file (architecture.md G-03; design WO-001 §8 "WO-002 adds validator
  verdicts"), so REQ-038.A1 is checked in `gradlew test` against the
  G1-baseline validator (decisions F15).
- **Governed interfaces touched:** `IPuzzleLibrary` (**implements**, locked
  tier — its shape and meaning must not change; a needed change is a
  hard-stop 5 for Jami) · consumes `Tangrams/puzzle.schema.json` (locked).
- **Out of scope:** drawing the picture or the silhouette (WO-003), saving
  progress (WO-004), any edit to the puzzle files themselves (content work is
  the owner's review loop, AGENTS.md rule 7).

# REQ-013 — Tray miniatures share one scale

## Statement
The game SHALL draw all tray miniatures at one common scale, and SHALL size each tray cell so that its piece fits in any turn.

## Rationale
Large pieces stay visibly larger than small ones, and the tray does not reflow when a piece is turned in it. SRC-009 asks that the tray shows the size a piece will have; one shared scale keeps the true proportions, and REQ-043 adds size marks.

## Rules
- Cell width = the piece's turn diameter × scale + 12 dp padding; turn diameters in units: large triangle 4.22, parallelogram 3.16, medium triangle 2.98, small triangle 2.11, square 2.00.
- The common scale is the largest one at which every tray row of the full set fits the screen width and each row is at most max(84 dp, 16 % of the screen height) tall. It is computed for the full set even when a puzzle uses fewer pieces, so a piece has the same miniature size in every puzzle.
- Each cell adds a 26 dp strip at its bottom for the turn buttons (REQ-044).

## Acceptance
- **A1** — On a 360 × 780 dp phone the smallest tray cell is at least 56 dp in both directions.
- **A2** — Turning a piece in the tray never changes any cell size.
- **A3** — The same piece has the same miniature size in a mini puzzle and in a full-set puzzle.

## Out of scope
Board scale.

## Assumptions
- ASSUMPTION: 12 dp cell padding and the 16 %-of-height row limit (prototype 0.3).

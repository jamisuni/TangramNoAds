# REQ-021 — Landing preview

## Statement
WHILE the player drags a piece, the game SHALL draw a dashed outline at the position where the piece would lock if released now, and SHALL draw nothing when no position is valid.

## Rationale
Makes the locking rule predictable, so a drop never surprises the player. It shows a valid position, not the correct one. The owner kept it (SRC-011, D4); it used to be off on the removed Hard level.

## Rules
- Updated at most once per displayed frame.
- The preview uses the same search as the drop (TYPE-004), so it never disagrees with the lock.

## Acceptance
- **A1** — Releasing the piece always locks it where the preview was drawn.
- **A2** — With no valid position in reach, no preview is drawn and the drop goes home (REQ-020).

## Out of scope
none

## Assumptions
- ASSUMPTION: a white dashed outline, 2.5 dp wide, over the silhouette. If the phone playtest shows children reading it as "the game says it goes here", the fix is a fainter, greyer outline, not removal.

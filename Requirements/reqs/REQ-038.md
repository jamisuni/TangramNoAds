# REQ-038 — Full-set puzzles of any shape

## Statement
The game SHALL only include puzzles that use every piece of TYPE-001 exactly once, except mini puzzles (REQ-045), and whose solution is a valid tangram: congruent pieces, no overlaps, connected through shared edges.

## Rationale
SRC-003: no hidden lock points ("nor we need suppor placing something middle without neighbors") is a rule of the runtime lock (REQ-019), not of the content: any valid tangram can be built edge-first, because the uncovered region always has a convex corner that is an anchor (SRC-011, F1). The former "edge-first" content rule (validator V11) was therefore never a restriction and is kept only as a printed build order for authors. The classic square is a valid puzzle again. SRC-008: "We can use random shapes … even rectangle is fine".

## Rules
- Every puzzle uses all seven pieces, except a puzzle of kind mini. *(Agent proposal, confirmed by the owner's lock SRC-014; first inferred from SRC-004)*
- Pieces touch along edges; a join at a single corner point does not count as connected.
- Checked by the puzzle validator rules V1–V6, V8–V10 and V12 in ../tools/validate_puzzles.py; V11 prints the build order.

## Acceptance
- **A1** — Every puzzle file passes the validator.
- **A2** — Each puzzle's printed build order places all of its pieces (it always does; the line is for authors).

## Out of scope
Other piece sets (idea #PieceSets).

# REQ-028 — A level changes the controls, not the puzzles

> **Withdrawn 2026-09-28 (SRC-011).** No difficulty levels (see REQ-004). The controls behave the same for everyone: TYPE-004 holds the one parameter set; the flip badge is always shown (REQ-018); the landing preview is always on (REQ-021); the timer is a plain on/off setting (REQ-031).

## Statement
The game SHALL apply the parameters of TYPE-004 for the chosen level and SHALL offer the same puzzles at every level.

## Rationale
The owner wants the game not too easy (SRC-002) yet simple to control; varying control forgiveness keeps one puzzle list for everyone.

## Rules
- Parameters: TYPE-004.

## Acceptance
- **A1** — On Easy, a piece dropped one turn step off still locks when a matching position is within reach.
- **A2** — On Hard, the same drop does not lock.

## Out of scope
Separate puzzle sets per level.

## Assumptions
- ASSUMPTION: difficulty changes the controls only (open question Q1 in ../Spec/05-open-questions.md).

# REQ-020 — Missed drop returns to the tray

## Statement
IF a dropped piece has no valid position by REQ-019, or is dropped outside the board or on the tray, THEN the game SHALL return it to its tray cell.

## Rationale
SRC-002: "not free drops but need make nice system can still drop easily".

## Rules
- There is no loose (unlocked) piece on the board at any time.
- The return animation lasts 180 ms and plays a soft sound; there is no failure sound or message.

## Acceptance
- **A1** — After any drop, the piece is either locked on the board or back in its tray cell.
- **A2** — No error message is shown for a missed drop.

# REQ-031 — Timer on screen

## Statement
WHERE the timer setting is Always, or it is Hard only and the level is Hard, the game SHALL show the running puzzle time in the top-right corner of the board.

## Rationale
Older players like a time goal; younger ones may feel pressured, so it is off by default below Hard.

## Rules
- Setting values: Hard only (default), Always, Never.

## Acceptance
- **A1** — On Medium with the default setting, no timer is shown.
- **A2** — On Hard with the default setting, the timer is shown and counts active seconds only.

## Out of scope
none

## Assumptions
- ASSUMPTION: the default is Hard only.

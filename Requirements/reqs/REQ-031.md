# REQ-031 — Timer on screen

## Statement
WHERE the timer setting is on, the game SHALL show the running puzzle time in the top-right corner of the board.

## Rationale
Older players like a time goal; younger ones may feel pressured, so it is off by default. The best time is shown on every solved card regardless (REQ-026), so nobody loses their numbers. The former "Hard only" default went with the levels (SRC-011, D7).

## Rules
- Setting values: off (default), on.
- The timer shows active seconds of the current puzzle only (TYPE-005, REQ-030).

## Acceptance
- **A1** — On a fresh install, no timer is shown.
- **A2** — With the setting on, the timer is shown and counts active seconds only.

## Out of scope
none

## Assumptions
- ASSUMPTION: the default is off.

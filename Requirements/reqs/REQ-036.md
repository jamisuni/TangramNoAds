# REQ-036 — Tablet layout

## Statement
WHERE the layout class is Tablet, the game SHALL support portrait and landscape and SHALL show the tray as a single row across the bottom.

## Rationale
SRC-001: "support larger tablet UI (bottom wider)".

## Rules
- Turning the tablet re-lays the screen and keeps every piece's state. *(Inferred from SRC-004)*

## Acceptance
- **A1** — On 1280 × 800 dp and 800 × 1280 dp tablets, the tray is one row.
- **A2** — Rotating mid-puzzle keeps every placed piece.

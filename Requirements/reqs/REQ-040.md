# REQ-040 — Puzzle difficulty and order

## Statement
The game SHALL list puzzles by their difficulty rating, lowest first, and by id within a rating.

## Rationale
A gentle start: SRC-008 asks for an easy start.

## Rules
- Rating: an integer from 1 to 5, shown as dots in the top bar.

## Acceptance
- **A1** — The first puzzle shown on a fresh install has rating 1.

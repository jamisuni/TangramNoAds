# REQ-025 — Continue or restart a half-done puzzle

## Statement
WHEN the player returns to a puzzle in progress, the game SHALL show it exactly as it was left, and WHEN the player presses Restart, the game SHALL return all its pieces to the tray and set the puzzle to New.

## Rationale
SRC-002: "If leaving puzzle half way can return it and restart if so wants or continue".

## Rules
- Saved per piece: tray or board, position, turn, mirror.
- Restart is shown only while the puzzle is in progress.
- The state survives closing the app. *(Agent proposal, confirmed by the owner's lock SRC-014; first inferred from SRC-004)*
- IF a saved piece is no longer a valid lock against the current silhouette (a puzzle changed in an update), THEN the game SHALL return that piece to the tray when the puzzle is loaded. (SRC-011, G6)
- Progress is stored per player profile; the first version has exactly one profile. *(Agent proposal, confirmed by the owner's lock SRC-014; first inferred from SRC-011: several profiles on one tablet are a release-two candidate, and the storage layout should not prevent it.)*

## Acceptance
- **A1** — Leave a puzzle with three pieces placed, come back: the same three pieces are in the same places.
- **A2** — After Restart, all the puzzle's pieces are in the tray and the puzzle time is zero.
- **A3** — A saved piece that overlaps the current silhouette's edge is in the tray after loading; the others stay.

## Out of scope
Undo of single moves. Several profiles (later).
